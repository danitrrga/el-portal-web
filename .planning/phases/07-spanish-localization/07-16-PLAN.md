read-throughs the phase's success criteria require.

than inheriting a green tick.

be fixed by shortening copy, because the plans that found them owned one file
each. This is the plan that owns the whole tree and can close them.

Output: a green matrix, a written evidence file, a reconciled suppression list,
and the end-of-phase human verification pack.

`scripts/audit-residual-strings.mjs` — a standalone Node script (no test
framework) that walks `src/**/*.{ts,tsx}` and reports every user-facing string
literal that never reached the catalogue. Its scan surface must cover ALL FIVE of
these categories, because each is a place a JSX-text grep is blind:
  1. JSX text nodes between tags — any run of characters containing at least one
     letter and at least two characters, outside `{...}` expressions;
  2. string-literal values of the attributes `aria-label`, `alt`, `title` and
     `placeholder`, including inside template literals;
  3. string-literal DEFAULT PARAMETER VALUES in component prop destructuring —
     the shape `CopyButton`'s `label = "Copy"` used, invisible to every
     JSX-oriented check;
  4. string literals in data modules under `src/data/` and in module-level
     `const` objects that feed rendering (the shape `HeroAppMockup`'s
     `HERO_IMAGE.alt` used);
  5. error, empty-state and status strings in client components, including
     `throw new Error("...")` messages that surface to a user.
It exits non-zero listing `file:line — literal` for every unallowlisted hit, and
prints `RESIDUAL_STRINGS_CLEAN` when there are none. Register it in package.json
