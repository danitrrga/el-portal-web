<objective>
Prove the phase, rather than assert it. Run the complete both-locale audit
matrix, re-measure the three criteria that fail silently, close every finding the
translation plans deliberately deferred, and assemble the evidence and human
read-throughs the phase's success criteria require.

Purpose: three of this phase's requirements have a failure mode with no error
message. I18N-06 (static prerendering) breaks silently if any `setRequestLocale`
was lost or any `generateMetadata` pulled a route dynamic. I18N-02 and I18N-04
break silently in the sense that a redirect looks like a working page. I18N-01 is
only true if nothing was missed across ~390 strings, which no reviewer can
confirm by reading.

One inherited risk is named explicitly because the cross-AI review rated it the
most likely surviving defect: the language switcher's touch-target width at
coarse-pointer widths. Plan 07-04 was revised to size each link with its own
horizontal padding and to measure it, but `touch-iphone` cannot launch on this
workstation, so the local suite can be green without ever having measured the one
rendering that matters. This plan closes that with a named, numeric check rather
than inheriting a green tick.

Waves 3 and 4 also deliberately deferred any containment offender that could not
be fixed by shortening copy, because the plans that found them owned one file
each. This is the plan that owns the whole tree and can close them.

Output: a green matrix, a written evidence file, a reconciled suppression list,
and the end-of-phase human verification pack.
</objective>

THE SWITCHER IS THE NAMED RESIDUAL RISK. `touch-targets.spec.ts:108` asserts
`r.width >= min && r.height >= min` — both dimensions — and skips entirely at
`width >= 768` (line 49). The switcher's `aria-hidden` separator means the
inline-text exemption at lines 94-104 does not apply to it. Below 768px TWO instances render — the `#mobile-nav` panel pair and the footer
pair — so both are in scope and the panel pair only exists in the DOM while the
menu is open, which a naive sweep will miss. Plan 07-04 sizes each link with
`min-h-11 min-w-11 px-3 justify-center` and records measurements at 390px; this
plan re-measures both pairs with the panel opened, because the project that
would have caught a regression may not have launched locally.

THE CROSS-LOCALE HINT IS THE SECOND RESIDUAL RISK. Plan 07-04 Task 3 adds a
`LocaleHint` that renders on English routes when `NEXT_LOCALE=es`. It is the one
component whose visibility depends on a cookie, so it is the one component that
can (a) reintroduce a hydration mismatch on all 8 English routes, (b) show
itself to a first-time visitor, which would be the silent browser-override this
phase exists to avoid, or (c) drag an English route out of static prerendering.
Assert all three explicitly rather than folding them into the general sweep.
