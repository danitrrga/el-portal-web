# Translation Flags — Plan 07-07 (SystemBlueprintSection, MethodologyPreviewSection)

Per-plan register file (see `TRANSLATION-FLAGS.md`'s ownership contract — this
plan writes only here, never to the shared file). Every Spanish string this
plan wrote in the `blueprint` namespace (`blueprintHeader.*`, `mockup.*`,
`methodology.*`) was checked against `SPANISH-VOICE.md`'s four wordplay
triggers, not sampled. Nine rows fired; the rest translate clean.

| Key | English | Spanish shipped | What was lost | Trigger |

| blueprint.methodology.heading | A method, not a vibe. | Un método, no una moda. | "Vibe" is culturally loaded, casual, feeling-based slang — it names an ambient, unexamined mood rather than a considered position. "Moda" (fad/trend) captures the "surface, non-substantive" half of the contrast but drops the sensory, feeling-first half; the line still reads as "rigor vs. looseness," but the specific "rigor vs. a feeling" opposition the English headline sets up is softened. | 1 (idiom/double meaning) |
