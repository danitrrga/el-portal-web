<objective>
Remove the `overflow-x-hidden` mask from `<body>`, clear every axe violation at mobile viewports,
and prove the whole phase: the full harness green, the build green, all 8 routes static, and the
frozen desktop design visually unchanged.

Purpose: RESP-02 exists because `overflow-x-hidden` on `<body>` clips overflow instead of
preventing it — it hides the symptom from both the eye and `documentElement.scrollWidth`, and it
silently breaks `position: sticky` for descendants. It can only come off after plans 05-03 and
05-04 fixed the overflow it was masking. This plan takes it off and then holds the whole phase to
the roadmap's eight success criteria.

Output: a clean `<body>` className, zero axe violations, a green `npm run audit:responsive`, and a
documented desktop-freeze verification.
</objective>
