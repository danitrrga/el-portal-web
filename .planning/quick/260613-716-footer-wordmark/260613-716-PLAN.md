# Quick Task 260613-716: Footer wordmark rebrand

## Goal

Rebrand the footer's large bottom string into an editorial, aesthetic
"EL PORTAL" in Special Gothic Expanded One that fills with a granular gradient
on hover. Design quality is the priority.

## Task

1. **Wordmark element** (`src/components/Footer.tsx`, `src/app/globals.css`)
   - Replace the serif-italic "Portal" watermark with a two-layer `EL PORTAL`:
     a chunky ghost outline (`-webkit-text-stroke`) + a grain-textured fill.
   - On hover: outline brightens, fill reveals left → right via an animated
     `@property --wordmark-reveal` mask = (linear sweep) ∩ (feTurbulence grain),
     so the advancing edge is noise-eroded (organic granular fill).
   - Fill is a volumetric, nonlinear surface: stacked radial blooms + directional
     luminance ramp + low-contrast fractal grain (soft-light), clipped to glyphs.
   - Right-aligned in the copyright row, sized so it spans Product→Legal columns
     at the same height as the copyright line.
   - `prefers-reduced-motion` fallback; no perpetual motion, no rAF.
   - **verify:** hover fills L→R, reverses on leave; rest = ghost outline.

2. **Brand lockup** (`src/components/Footer.tsx`)
   - Swap the brand-column serif "Portal" for the canonical `ElPortalWordmark`.
   - Update copyright text "Portal" → "El Portal".
   - **verify:** footer brand mark matches the nav PORTAL lockup; lint clean.

## Decisions (captured live with the user)

- Word: **EL PORTAL** uppercase (Special Gothic display treatment).
- Fill: **pure-white → volumetric silver** grain (monochrome, ink-grey shadows).
- Resting: **faint ghost outline** that brightens on hover.
- Depth comes from **gradient contrast**, not brightness; grain kept quiet.
- **Deviation:** uses `background-clip: text` (CLAUDE.md bans it for gradient
  headings as an AI tell) — accepted here as a deliberate, art-directed
  decorative watermark, flagged to and approved by the user.
